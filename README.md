# MonStatus

モンストのスケジュール、ガチャ、クエスト、ラッキーモンスター、モンスター図鑑を検索できる非公式サイトです。日時は日本時間で表示します。

公開サイト: https://monkuso.github.io/MonStatus/

## 閲覧できる情報

- スケジュール: 開催中・開催予定・指定日で絞り込み。常設やチケットの情報はガチャの登録情報から確認できます。
- ガチャ: 開催名、必要アイテム、参加条件、ピックアップ、取得済みの公式提供割合。割合の適用期間と確認日時を表示します。10連への割合の共有は、公式説明に「シングル、10連共通」とある場合だけ行います。
- クエスト: ステージ、ギミック、注意点、経験値、消費、開催期間、取得済みのみんなのクリアモンスター。
- ラキモン: 公開された対象期間、モンスター画像、入手クエスト、運極所持数の特典。
- モンスター: 画像、属性、ステータス、アビリティ、ストライクショット。

ゲーム33.0.0の実サーバーで取得したマスターと、起動中の正規クライアントで観測した公開情報を使用しています。モンスター19,499件、ステージ9,484件、クエストグループ5,921件を収録しています。画像12,086点を収録し、一覧では表示に必要な画像を遅延読み込みします。

## 更新範囲

GitHub Actionsが約30分ごとに配信目録とマスターをGETで取得し、サイズ、CRC32、ZIP、MessagePack、参照関係を検証して公開します。PCを起動し続ける必要はありません。GitHub側の混雑で定期実行が遅れる場合があります。

ゲーム接続設定はRepository Secretの `MS_GAME_CONFIG` だけに保存します。ゲームセッションや署名付き要求の失効時は設定の更新が必要です。自動ログインは実装していません。

ガチャの開催一覧、提供割合、ラキモンはクライアントで確認したスナップショットを保持しています。マスターの更新日時とは別に確認日時を表示します。これらの一覧の継続取得と、全ステージのクリアモンスター集計の取得は未完了です。現在のクリア集計は5ステージ分で、未取得の実績や確率は生成しません。

取得・検証に失敗した場合は最後の検証済みスナップショットを元の日時で配信し、Actionsを失敗として記録します。ブラウザーの更新ボタンと5分ごとの再確認は、公開済みデータを再読み込みします。

## ライブラリと検証

検索、日時判定、図鑑の参照、画像の解決、ラキモンのドロップID対応をESモジュールとして利用できます。Pythonの検証は配信データの破損と非公開項目の排除を確認し、JavaScriptの検証は日時境界、JST、検索、参照整合性、実画像、提供割合の精度を確認します。
