# MonStatus

モンストのイベント開催期間を検索できる非公式トラッカー。

公開サイト: https://monkuso.github.io/MonStatus/

開催中・開催予定、今日と明日の予定、JSTでの指定日検索、名前検索、並び替え、お気に入り保存に対応します。同じクエスト・名称・期間の記録はまとめて表示します。常設・長期日程と条件付きの日程は表示設定で切り替えられます。

2026年10月13日22:28 JSTに実サーバーから取得し、配信サイズ・CRC32・ZIP・MessagePackを検証したイベント情報1185行を収録しました。通常日程257行、条件付き日程928行です。実際の出現時間・参加条件はゲーム内でご確認ください。

各イベントのカードには、該当ステージの `stage_gimmicks` マスターから取得したギミック発生状況を12スロットで表示します。グループ内の全ステージの `gimmick_flag` と `highlight_gimmick_flag` を OR 合成し、両方のビットが立つスロットは「重要」として強調表示します。スロットの対応先ラベルは `libmonsterstrike.so` の `StageGimmickIcon::updateGimmckDisp` から得たビット順序に基づき、1〜12 の番号で表示します。各スロットの名称対応はゲーム内アイコンでご確認ください。

モンスター情報として「出現候補ボス」と「推奨モンスター」をカードに表示します。出現候補ボスは `wanted_bosses` と `wanted_boss_groups` から、イベントの開始・終了時刻と交差する期間のボスを `order` 順に表示します。推奨モンスターは `chars` マスターから、ステージ属性に対して有利な属性 (火→水→木→火、光↔闇) を持ち、レアリティ降順で選んだ候補です。各候補の属性バッジ、名前、レアリティ (★数) を属性色のタイルとして表示します。ゲーム内の実アイコン画像は収録していません。本サイトの「推奨モンスター」はマスターデータから算出した候補で、実際の攻略情報・各ユーザーのクリア実績ではありません。

## クラウド同期

GitHub Actionsの定期実行でゲーム配信目録とイベントマスターを取得し、検証済みの公開データとサイトをGitHub Pagesへ配信する構成です。PCやエミュレーターの常時起動は不要です。実行予定は毎時17分・47分（UTC）、約30分間隔です。GitHub側の混雑で実行が遅れる場合があります。

ゲーム接続設定はRepository Secretの `MS_GAME_CONFIG` で受け取ります。ゲームセッション、署名付き読み取り要求、配信ZIPの鍵を含む設定をソースや公開ファイルへ保存しないでください。取得処理はGETのみで、9テーブル (`stage_groups`, `stage_group_events`, `stage_group_kind_events`, `stage_group_cycle_events`, `stages`, `stage_gimmicks`, `chars`, `wanted_bosses`, `wanted_boss_groups`) の配信サイズ・CRC32・ZIP・MessagePackと日程形式を検証します。認証失敗や検証失敗時は公開を中止し、最後に正常公開したデータを維持します。

保存したゲームセッションや署名付き要求の有効期間には依存します。期限切れ・失効時はSecretの更新が必要です。自動ログインや認証の自動更新は実装していません。最新の実行状況はリポジトリのActionsで確認できます。定期実行の継続はGitHub Actionsの稼働条件にも依存します。

サイトは取得成功日時を表示し、90分以上古くなると同期遅延を表示します。公開データを5分ごと、および画面へ戻ったときに再確認し、検索条件とお気に入りを保ちます。「更新」は公開済みデータの再読み込みです。

## 画像

オラゴンとお気に入りのハートはモンスト32.1.1の実アセットを使用しています。ゲーム画像・キャラクターの権利は株式会社MIXIに帰属します。APKやゲーム本体は収録していません。

## ライブラリと検証

ブラウザーで使うデータ取得・検索・開催期間の分類処理をESモジュールとして分離しています。時刻分類は表示上、開始・終了の秒を期間内に含めます。APIの参加条件やゲーム内の境界判定を保証するものではありません。

セッション情報、認証値、署名素材はソースと公開サイトに収録していません。Pythonの単体テストはCRC破損、ゲーム側のエラー応答、不正な期間、非公開項目を公開データへ混ぜないことを検証します。JavaScriptのテストは日時境界、JSTの日付範囲、Unicode検索、お気に入り、重複日程、同期遅延、実データの形式を検証します。
